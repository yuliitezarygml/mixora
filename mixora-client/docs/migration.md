# Перенос исходного клиента

Источник: `../mixora-music-client/app`, 78 HTML-экранов и общие компоненты из собранных JavaScript-пакетов. Полный список исходных HTML и подключённых файлов — `screen-inventory.json`.

Объём: сохранить существующий самостоятельный клиент React/JavaScript; перенести экраны и исходные CSS-классы; связать действия с библиотекой Mixora и официальным SoundCloud API. Исходную папку не изменять.

Порядок переноса:

1. Моя волна: сохранённые настройки, рекомендации по доступным метаданным, исключения, продолжение очереди, волна по треку/исполнителю.
2. Каталог: поиск треков, исполнителей и плейлистов; страницы исполнителя, альбома/плейлиста и их подразделы.
3. Коллекция: фильтрация и сортировка, сохранённые альбомы/подборки, редактирование личных плейлистов, история.
4. Обзор: жанры, подборки, подкасты, детские категории, профиль, итоги и истории; отдельные экраны для оставшихся маршрутов.
5. Плеер: полноэкранный режим, управление очередью, контекстные действия и настройки.
6. Проверки маршрутов, логики и сборки; проверка неизменности исходных стилей.

Границы данных: алгоритм рекомендаций, подписка, афиша, видео, тексты и серверная редакция Яндекса не содержатся в клиентской сборке. Они не могут стать рабочими простым копированием. Поддерживаемые действия реализуются через Mixora/SoundCloud; остальные экраны должны явно показывать отсутствие данных, без выдуманных концертов, рейтингов или текстов. Упоминание страницы в маршрутах не считается подтверждением полной функциональной идентичности.
